# Modulo Android de Cinema

Modulo de aplicacion Android de Cinema; contiene la configuracion de compilacion, dependencias y fuentes Kotlin/Compose. La guia completa de ejecucion y arquitectura se encuentra en [`../README.md`](../README.md).

Desde la raiz del proyecto, sus tareas principales pueden ejecutarse con:

```bash
./gradlew :app:test
./gradlew :app:assembleDevDebug
```
